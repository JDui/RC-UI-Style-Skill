# 视觉系统

[2.0 参考图](../assets/style-reference-v2.webp) 只用于构图、色彩和表面层级。插画、界面文字和模拟数据不代表实际业务或文案规范；新 UI 文案遵循 [文案规范](content-style.md)。

## 材质与配色

先按 `SKILL.md` 选择表现强度，再分别确定主题、材质与环境层。三者不绑定：深色可以是实色，浅色可以是玻璃；`showcase` 也不意味着所有表面透明。具体参考站证据与 RC 适配见 [效果目录](kiseki-effects.md)。

优先选择一个与项目用途一致的基底：

| 模式 | 基底 | 面板 | 正文 / 次要文字 | 推荐用途 |
|---|---|---|---|---|
| 浅色清透 | 冷白、浅蓝灰 | 半透明白，必要时提高不透明度 | 近黑 / 中性灰 | 图库、轻工具 |
| 深色克制 | 蓝黑或中性炭灰 | 深灰蓝分层 | 近白 / 灰蓝 | 仪表盘、桌面浮层 |

- 示例色值仅为起点：浅底 `#F0F1F4`、深底 `#0B1018`；浅正文 `#1D1D1F`、深正文 `#F8FAFC`。
- 深色不是机械反相；降低环境色饱和度，以边界、明度和少量高光区分层级。不要让图片因暗色主题统一变暗。
- 强调色与背景色分离；允许蓝、青、灰紫、低饱和玫瑰。WebGallery 的主题生成会改变 CSS 基准蓝色，不能据此固定全产品为蓝色。
- 文字、焦点、按钮需在实际透明叠底上检查对比度。模糊不受支持时使用不透明面板，不保留不可读的透明底。
- 优先 1px 细描边、极淡内高光、软阴影。Blur 可从 12px 起步，内容型面板可到 24px；没有背景纹理时不要为了玻璃而制造噪声。
- 背景网格、渐变、呼吸边框属于项目可选项，不是全局默认装饰。

### 材质模式

| 模式 | 适用位置 | 实现与回退 |
|---|---|---|
| `glass` | 有环境内容的导航岛、浮层、少量主面板 | 用半透明底、细边、内高光形成层级；blur 失效时提高不透明度 |
| `solid` | 高频操作、正文、复杂背景上的信息卡 | 不依赖背后内容也有稳定对比度，作为玻璃的首选降级 |
| `outline` | 稀疏次级分组、筛选区或背景足够稳定的卡片 | 用边线与间距分组；背景变化后不满足可读性就转 `solid` |
| `flat` | 编辑密集区、嵌套列表或低性能模式 | 去除不必要阴影、滤镜与装饰层，保留边界、状态和焦点 |

材质切换只改变表面表达，保留主题、布局尺寸、选中状态、输入值与语义色。不要让 outline 模式把文字放到不可预测的照片上，也不要用全局 opacity 同时降低内容与背景的不透明度。

### 环境层与局部光效

- 将背景色场、柔和光晕和边缘高光放在内容背后的独立装饰层；不占布局，不截获指针，不进入无障碍树。
- `restrained` 默认静态或无环境层；`expressive` 选择少量局部光晕；`showcase` 可采用更明显的背景编排。先选一个主要环境系统，避免多个持续动画争夺注意力。
- 光标聚光只在明确目标内响应精细指针，不代替 focus 或选中状态。键盘焦点使用稳定高光；触摸使用普通 press/selected，不强求追光。
- 局部视差只影响装饰背景或独立内层，不能让可点击目标、文字输入、滚动坐标或媒体审阅基准漂移。倾斜、聚光、hover 抬升若同时存在，应分层合成，避免争写同一 transform。
- 允许环境色跟随内容的概括色调，但将色调限制在周围装饰，照片、视频、画布和导出预览本体不加滤色、不降亮度。
- 同时检查最亮与最暗的背景位置。对比不足时增加表面遮盖或改用实色，不靠更强 blur 掩盖问题。低性能和减少透明度需求下优先实色或 flat。

## 圆角层级

| 层级 | 合成基准 | 例外 |
|---|---|---|
| 内嵌区、徽标 | 5–8px | 状态标签可胶囊 |
| 按钮、输入 | 8–12px | Meter 7–8px；AXIVER 9px；Core 示例6px |
| 卡片 | 12–18px | 仪表盘统计小卡可到22px |
| 主面板、弹层 | 18–26px | AXIVER17px；Meter12px；Geargrade大面板约29–32px |
| 进度条、状态、特定导航 | 全圆角 | 不扩散到所有操作按钮 |

相邻组件采用少量一致层级；嵌套圆角应随内缩减小，避免外框小圆角、内框反而更圆。视觉尺寸改变时重新判断，不把所有桌面组件强制改成24px圆角。

## 排版与密度

- 使用系统无衬线字体：Segoe UI / PingFang SC / Microsoft YaHei UI / Noto Sans SC 等系统回退；不额外加载不必要字体。
- 工具正文通常 13–14px；次级信息 11–12px，仅在可读且不承载关键决策时更小。避免把源项目的10.5px元信息当全局正文标准。
- 标题靠字重和层级，不堆大字。Geargrade 的大标题是仪表盘例外，小浮层不照搬。
- 图标一般 16–18px；保持统一线宽、容器、基线及视觉重心。使用现有图标库，不混入emoji作普通操作图标。
- 基础间距采用4px网格，组件内常用6/8/12px，面板16/20/24px。细节允许光学调整。
- 桌面紧凑图标按钮可32–36px，内容型按钮约36px高；触控环境将实际命中区域扩展到至少44px，避免不可点击的小图标。
- 工具栏对齐同一高度；标题、描述、输入、错误信息保持一致起始边。长文本截断时保留可访问完整值。
- 展示页可在首屏使用一处更鲜明的标题或分组字标，正文仍遵循可读行长与密度；不把主页标题规格扩散到编辑器、数据行或设置表单。字体缺字或加载失败时系统字体能完整显示中日文。

## 响应式

媒体图库随有效宽度增加列数，表单保持适宜行长。超宽屏不要只有固定16:9中心盒子，也不要把每行文本拉满屏。容器上限由内容用途决定，不能将某一仓库2880px上限升格成统一限制。

小屏时允许工具栏换行、侧栏收纳、表格局部滚动；关键操作不被浮层、标签、收藏按钮或滚动条遮住。不要以缩小全部字体解决溢出。

Bento 或跨列卡片在窄屏按任务顺序展开，DOM 阅读顺序与视觉顺序一致。悬浮导航岛预留安全区和滚动底部空间，200% 缩放时允许换行或收纳，不覆盖最终一行内容。不要为保留桌面构图而禁止页面自然滚动。
