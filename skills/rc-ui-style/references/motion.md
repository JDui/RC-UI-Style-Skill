# 动效系统

## 默认节奏与项目例外

下表是跨项目合成起点，不声称每一项已在每个仓库实现。

| 类型 | 建议 | 典型曲线/变化 |
|---|---|---|
| 颜色、边框、hover、press | 120–180ms | ease或轻缓出 |
| 选中底板、短内容切换 | 180–280ms | cubic-bezier(.16,1,.3,1) |
| 面板进入、抽屉短行程 | 220–320ms | cubic-bezier(.22,1,.36,1) |
| 面板退出 | 140–220ms | 较快退出，不与进入同样拖长 |
| 真正忙碌状态 | 按状态选择约1.3–4s | 低强度循环，终态停止 |

- 进入以opacity + 4–8px位移为主，可配scale .97–.99→1；退出更快。
- AXIVER胶囊可保留400ms展开、72%处仅超宽3px后归位、320ms收起。**轻弹性允许，夸张果冻不默认。** 这类尺寸动画是小型浮层特例，不套给大型列表。
- Geargrade存在520–720ms的页面/大卡入场和32px抽屉行程；已有项目可保留其节奏，新工具页不要默认引入长入场。确切源码值见来源表。
- 卡片错峰只用于短列表首屏，少量20–40ms增量即可；设总上限，不让大量数据等待入场。滚动回看不反复播放。
- 优先transform/opacity。尺寸或位置重排必须有理由并实测；拖动中关闭位置过渡保持跟手。

## 按表现强度选用

- `restrained` 保持以上短节奏，高频操作不重复入场；数据更新不让整页闪动。
- `expressive` 可选择短首屏错峰、局部聚光、卡片与媒体过渡；每项均有用途，不因同屏多个组件加载就同时播放所有动画。
- `showcase` 可加强首屏编排与环境层，但内容、导航和输入立即可用，不设置等待动画结束才能进入的门槛。
- 网站观测参数与 RC 推荐值分别记录在 [效果目录](kiseki-effects.md)；接入细节读 [实现配方](effects-recipes.md)。不能把参考站一个长动画的时长升级为全产品默认。

## 选中底板

让底板移动而非整排按钮抖动。先测实际选中项的offset与width，再更新位置。考虑容器滚动、resize、字体与文本变化；切换中断时从当前呈现状态继续或直接到最终状态，不能排队播放历史点击。

## 状态驱动

- 业务忙碌的呼吸边框/扫光只在工作中显示；成功、失败、取消均停止。
- 页面不可见时暂停无意义循环。不能用动画装作任务还在运行。
- 已经生成的文本可以短暂渐进呈现，但标明是呈现效果，不能伪装模型思考或实际流式生成；复制、编辑立即提供完整值。
- 保存失败或取消时还原真实UI状态，动画完成不是业务完成。

## 装饰氛围与指针增强

- 将装饰氛围标为独立视觉层，不使用进度条、忙碌标签或其他暗示任务状态的结构。持续装饰须有关闭入口；页面隐藏时暂停，恢复时不补播后台累计帧。
- 光标聚光和局部视差只在允许精细指针、可见、正常性能且未请求减少动效时运行；键盘/触摸得到稳定的焦点或按压反馈。
- 指针事件只保存最新坐标，通过至多一个待执行的 animation frame 更新。先批量读取几何，再写 CSS 变量；离开、失焦、隐藏或销毁时取消帧并还原样式。
- 多种 transform 分配给不同内层或统一合成。不要用 hover CSS、拖动 JS 与滚动动画同时覆盖同一个元素的 transform；可点击命中区保持稳定。
- 首屏揭示采用渐进增强：没有 JS、初始化失败或观察器不可用时内容本来就可见。有限错峰只发生一次，用户快速滚过或减少动效时直接显示终态。

## 主题、内容切换与中断

- 主题和材质的最终值由明确的状态更新完成；过渡仅呈现变化，不承担保存成功的语义。连续切换要取消或接续当前动画，以最后一次选择为准。
- 共享元素或视图过渡是可选增强。旧视图捕获、媒体加载或 API 失败时仍能完成导航，保持可用的直接切换路径。
- 圆形揭示、位移等明显空间变化仅在适合的强度档使用；减少动效时即时切换，不通过缩短到极小正时长继续播放空间动画。
- 动画结束或取消都清理临时层、监听器、busy 标志与内联样式；焦点应落到有意义的目标，不能依赖动画结束事件才能完成操作。

## 减少动效与性能

- 尊重prefers-reduced-motion；移除位移、缩放、弹性和装饰循环，关键状态即时可见。可以保留不造成运动的短颜色反馈，也可直接关闭。
- 监听偏好的运行时变化；切入减少动效后立即取消进行中的帧和过渡，并显露最终内容。不能只在页面首次加载时判断一次。
- 提供低性能路径：关闭backdrop blur、降低阴影与滤镜叠加，用更不透明表面维持可读性；不要以透明空壳作为回退。
- 避免永久will-change、大面积连续blur动画和多层滤镜。仅在必要活动阶段使用，结束释放。
- 验证快速开关、连续点击、切换主题、后台再返回、取消/关闭中断，避免残留transform、错误高度或卡死busy状态。
- 对可复用脚本提供明确初始化与销毁：各 root 独立保存状态，重复初始化幂等或先清理旧实例；卸载时移除监听器、observer、媒体查询监听和待执行帧。低性能开关与输入方式变化同样即时生效。

## 模板使用

`assets/rc-ui.css`只提供基础时长、缓动和短进入效果，不实现完整业务状态机；选中底板示例在`assets/components.html`。可选增强使用`assets/rc-effects.css`、`assets/rc-effects.js`与`assets/effects.html`，具体能力和生命周期以[实现配方](effects-recipes.md)为准。组件规则中的轮播、播放器、共享元素等模式不等于上述资产已经提供完整组件。按项目现有动画系统接入，不为了本skill添加大型动画依赖。
