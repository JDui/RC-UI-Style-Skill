# RC 2.0 UI 文案规范

## 适用范围

适用于导航、标题、按钮、筛选、表单、提示、空状态、加载状态、错误、通知、设置说明、示例占位文案，以及 Agent 为新界面生成的可见文字。无障碍名称及用户可读日志同样适用。用户提供的原文、法律文本、正式品牌名称可例外，但不能把参考图的文字自动当作产品文案。

**优先级：准确表达动作、对象、状态与限制 > 简短 > 语气。** 简短不得牺牲恢复操作、风险说明、必要业务信息或无障碍名称。

## 强制规则

1. **直述功能**：标题写页面、模块或对象名称；按钮写动作；状态写正在发生或已发生的事实。不要用口号、情绪、比喻代替功能。
2. **删除修饰**：移除夸张形容词、空泛评价、拟人化感叹、广告口号和重复提示，例如“极致”“震撼”“丝滑体验”“更懂你”“开启全新旅程”“令人惊艳”“探索无限可能”。技术参数、确有证据的比较或用户指定正式名称不因包含形容词而删除。
3. **避免冗余**：不使用“为您精心准备”“马上为你呈现”“非常感谢耐心等待”“一切都已就绪”等无实质信息语句；不用感叹号、颜文字或 emoji 装饰常规 UI。
4. **动作明确**：按钮优先写“动词 + 对象”，例如“导出照片”“重试加载”“保存设置”。空间紧张且上下文唯一时可以用“保存”“返回”“取消”，不能缩成失去含义的字词。
5. **状态准确**：区分加载中、处理中、已保存、失败、已取消和部分完成；进度必须来自业务数据。错误须给出原因或可操作的下一步，必要时显示错误码。
6. **单位与数字**：长度、耗时、数量、容量和百分比采用统一单位；数值与标签对应，不使用无依据的宣传数字。
7. **术语稳定**：同一对象使用统一名称，不在不同页面无定义地交替写“素材/作品/资源”；不因追求短句破坏专业术语。
8. **阅读优先**：辅助说明应回答一个具体问题；长操作或高风险动作保留必要解释。技术、法律与安全提示不受任意字数上限约束。

## 文案示例

| 场景 | 不采用 | 采用 |
|---|---|---|
| 作品入口 | 在光影里发现更多可能 | 作品图库 |
| 主要动作 | 开启一段精彩探索之旅 | 浏览作品 |
| 数据面板 | 一切尽在掌握 | 数据概览 |
| 加载 | 正在为您精心准备内容 | 加载中 |
| 保存成功 | 太棒了，所有更改已完美保存！ | 已保存 |
| 保存失败 | 哎呀，发生了一点小意外 | 保存失败。请重试 |
| 无搜索结果 | 暂时还没有发现心仪的内容 | 无匹配结果 |
| 空收藏 | 还没有属于您的精彩收藏 | 暂无收藏 |
| 处理中 | 正在见证奇迹发生 | 正在处理 3 / 12 |
| 动效开关 | 享受更加丝滑流畅的体验 | 启用界面动效 |
| 主题 | 沉浸在静谧夜色中 | 深色模式 |

“正在处理 3 / 12”仅在真实任务能提供该数字时使用。这些短句是示例，不要求所有项目照搬。

## 按组件写法

- **导航/标签**：对象名或页面名。例：图库、时间线、预设、设置。
- **按钮**：动作与结果。例：导入照片、查看详情、重新规划。
- **开关**：被控制的设置。例：自动同步、背景动效、低性能模式。
- **提示**：解释条件与限制。例：仅支持 JPG、PNG 和 WebP。
- **成功**：结果与必要位置。例：已导出 24 张照片。
- **失败**：问题与恢复入口。例：网络连接失败。重试。
- **确认**：对象、影响与不可逆条件。例：删除 12 个文件？此操作无法撤销。
- **演示**：说明非真实数据。例：演示数据，不会保存。

## 与视觉稿的边界

- [RC 2.0 参考图](../assets/style-reference-v2.webp) 用于布局、材质、导航、卡片和色彩分层。图中的英文标题、口号、数据与小字不具有文案规范效力。
- showcase 档可以使用更多空间和媒体，但 **文案仍必须功能化**；showcase 不是允许营销口号的例外。
- 可复用组件示例必须遵守本页；历史截图与第三方引用不做伪造性修改，必要时标明非规范性。
- 参考图不能证明文字准确、数字真实或页面渲染正确。

## 验收

- 检查所有可见文案、按钮可访问名称、空状态、加载、错误、成功、取消和部分成功状态。
- 删除不传达动作、对象、事实或限制的修饰性句子；使用操作或状态说明替代宣传口号。
- 快速切换、错误恢复和减少动效模式下文案不失真、不被动画截断。
- 校对中日英混排、数字、日期、单位、标点、缺字与换行；移动端完整含义仍可读。
- 记录未检查页面；规范检查不等于所有业务文案已获验证。
