# 组件与反馈

## 按钮

| 状态 | 推荐处理 |
|---|---|
| 常态 | 主操作强调色；次操作中性低对比表面；文字与图标居中对齐 |
| Hover | 背景/边框轻增亮；可选上移1–2px，不改变周围布局 |
| Press | 回落、阴影减浅，或scale约.98；既有项目仅亮度变化也成立 |
| Focus-visible | 独立清晰轮廓2–3px与适度offset，不依赖hover |
| Disabled | 取消抬升/按压，降低但不抹掉可读性；原生disabled或完整aria语义 |
| Loading | 保留按钮宽度，明确忙碌原因；根据业务阻止重复提交；结束恢复状态 |
| Danger | 独立红色语义，不随品牌换色；确认行为由操作风险决定 |

主次按钮同高、图标同尺寸、间距一致。不要同时大幅缩放、抬升、旋转、彩虹发光。复杂页面默认一个明确主要动作，勿把所有按钮都做强渐变主按钮。

低透明按钮需要真实叠底测试。透明文字按钮使用明确命中容器，hover的视觉区域与点击区域对应。仅有图标时提供可访问名称；tooltip不能作为唯一名称。

## 输入、开关与分段导航

- 输入采用与按钮一致的小圆角，焦点高于hover；错误信息与正常帮助占位一致，避免突然推挤布局。
- 开关应有明确开/关和禁用状态，不仅靠颜色区分。保存失败不能继续呈现已保存。
- 分段导航可用一个滑动选中底板；按照真实元素几何测量位置与宽度，处理字体加载、缩放、容器resize和长标签。不要固定三等份假设所有标签等宽。
- Tabs实现键盘方向键/Home/End、选中语义与关联面板；普通过滤按钮用aria-pressed，不冒充tab。
- 切换后的内容淡入应短，不叠积旧动画。快速反复点击以最终状态为准。

### 导航岛与上下文切换

- 将少量顶级目的地组成独立导航岛，当前项保持稳定可辨识；全站导航使用链接与 `aria-current`，同页面板切换使用 tabs，动作使用按钮，不混用语义。
- 底板按真实标签几何测量；窗口变化、字体加载、文本变更、容器滚动后重新对齐。宽窄标签混排也不能依赖等分宽度。
- 导航收缩、上下文标题替换或图标展开应保持主入口可找到；只替换相关辅助信息，不让当前焦点所在按钮突然消失。
- 浮动定位时预留内容和安全区；触控可点击，键盘可遍历，狭窄视口可换行、横向滚动或收纳，不用 hover 作为唯一发现方式。
- 入口较多或任务复杂时保留侧栏/列表。导航岛是信息层级选择，不是所有页面的默认外观。

## 卡片、列表与状态

- 卡片内容主次明确，标题与元信息分层；缩略图比例服务内容而不是强制全部16:9。
- 选中、hover、键盘focus三种状态区分；不要用永久抬升表达选中。
- 角标、菜单和收藏按钮预留独立位置，hover时不互相覆盖。
- 状态胶囊用短文本和必要图标；成功绿、警告橙、危险红的语义独立于强调色。
- 额度/数量用tabular-nums；进度必须来自真实状态。无法估计时用明确的不确定进度，不展示虚假百分比。
- 空、失败、加载、部分成功状态与正常布局同等设计；错误反馈说明恢复方法，不靠无限spinner掩盖失败。

### Bento 与局部交互卡片

- 根据内容权重分配卡片跨度；主内容、状态摘要与快捷入口可以不同尺寸。密集表格和连续编辑任务优先常规布局，不硬拆成大量卡片。
- 桌面保留稳定网格和明确分组，小屏按任务顺序自然堆叠；长标题、无图、加载失败和空数据不改变主要入口位置。
- hover 可强化边线、局部光晕或轻微抬升。聚光/倾斜仅作可关闭增强，卡片是否可操作通过结构、文案和焦点共同表达。
- 不嵌套交互元素；卡片同时提供主链接、收藏和菜单时，将这些入口做成独立兄弟控件，保留各自命中区与语义。不要让装饰层覆盖控件。

### 轮播、媒体展开与共享元素

- 轮播只用于适合逐项浏览的精选内容；搜索结果、重要状态和主要操作不藏在轮播的后几页。默认手动翻页，提供有名称的前后按钮和当前位置。
- 支持触控拖动时保留页面纵向滚动；键盘与按钮完成同样任务。若产品确需自动轮换，提供暂停，在焦点/交互、隐藏页面和减少动效时停止。
- 媒体从缩略图展开时，可以用共享元素保持位置与内容连续性；匹配明确的资源身份，处理加载失败、返回来源消失与快速切换。动画 API 不可用时立即切换普通视图。
- 展开层遵循实际语义：模态查看器有关闭入口、ESC、焦点约束和返回焦点；普通详情导航保留地址、返回行为与阅读位置。不要用共享元素动画冒充焦点管理。
- 真实媒体的色彩、比例与清晰度独立于周围环境效果。展示过程可裁切装饰缩略图，但审阅、编辑、对比视图必须明确完整画面范围。

### 播放器、歌词与时间信息

- 只在具有真实媒体播放能力的界面引入播放器；播放、暂停、进度、曲目、错误和缓冲状态均来自实际媒体事件，不让按钮只改变图标。
- 歌词高亮来自可用时间戳；没有时间数据就显示静态文本。减少动效时可切换高亮但不平滑滚动；用户主动阅读或选择文本时停止自动跟随，并提供恢复跟随入口。
- 内容变化不抢焦点，不把逐帧进度或每句歌词送入高频 live region。持续播放与音频启用遵循明确用户操作。
- 时钟、天气、在线状态和近期活动分别交代来源与更新时间；数据不可用时显示未知或失败，不用演示值掩盖接口状态。效果示例中的模拟状态必须明确标识。

## 浮层与渐进披露

小工具可在收纳态保留关键值，展开后显示细节。可点击/键盘打开，不能仅依赖hover。触控不应要求模拟鼠标悬停。

浮层与触发器之间避免命中空隙导致误关闭；离开延迟可用于短暂容错，不拖慢用户主动关闭。ESC、关闭按钮、外部点击和焦点回退按该组件语义实现。模态框需焦点约束，普通popover不一律套模态逻辑。
