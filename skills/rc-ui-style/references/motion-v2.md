# RC 2.0 动效连续性规范

本规范补充 [原有动效系统](motion.md)，目标是消除切换闪断、突兀显隐和连续点击造成的状态错位。保留原有 restrained / expressive / showcase 强度档与 glass / solid / outline / flat 材质体系。下列数值是新界面的建议起点，不覆盖已有项目实测通过的节奏。

## 过渡原则

1. **状态先行**：业务状态先提交，动效仅负责表现；动画完成事件不决定任务是否完成。
2. **一个连续过程**：同一次切换的退出、位移、进入按统一时间线编排；避免旧内容瞬间消失而新内容延迟出现的空白帧。
3. **保留节点身份**：优先稳定挂载、更新属性和局部内容。不要为动画无条件销毁并重建整个视图、图表或控制岛。
4. **可中断**：新的交互取消、反转或接续当前过渡；以最后一次输入决定终态。不排队重播过期动画。
5. **共享空间关系**：导航底板、浮层、列表筛选和图表切换按实际几何与内容状态计算，不使用固定等宽假设。
6. **输入跟手**：拖拽、裁切、滑块跟手更新不加位置补间或弹簧；释放后才应用可选回弹。
7. **文本独立**：动效不产生宣传性文案；业务提示遵循 [UI 文案规范](content-style.md)。

## 默认时长与缓动

| 情况 | 建议时长 | 实现方式 |
|---|---|---|
| Hover、按下、颜色/边框反馈 | 100–180ms | ease-out，保持布局稳定 |
| 选中底板、筛选高亮 | 180–260ms | translate/scale，按真实几何测量 |
| 小面板折叠/展开 | 220–360ms | 容器尺寸与内容分层；内容短延迟但不等待动画结束 |
| 场景切换、内容替换 | 240–400ms | 退出与进入交叠，不强制整页转场 |
| 退出、关闭、取消 | 140–220ms | 直接收敛到终态 |
| 首屏局部错峰 | 每项 20–40ms，总错峰不超过 160ms | 限量播放，离屏不累计 |

可从 cubic-bezier(.22,1,.36,1) 和 cubic-bezier(.16,1,.3,1) 起步。已验证的小型容器形变允许轻量回弹；大面积内容避免明显过冲与高频弹性。“丝滑”不是验收条件，应以可复现的交互和帧记录描述表现。

## 按强度档分配

- restrained：微交互与短内容切换为主；编辑器、输入控件与参数滑块优先响应速度。
- expressive：图库、仪表盘可选共享元素、卡片小位移、图表插值；每次交互保留一个视觉重点。
- showcase：可加强首页环境层和首屏过渡；导航和内容立即可用，且不放宽文案规则。

## 页面和内容切换

- View Transitions 仅适用于具有稳定身份的对应元素；不支持、失败或减少动效时直接切换。
- 无 View Transitions 时，先更新业务与路由状态，再对稳定容器使用 WAAPI/CSS 的 opacity/transform 过渡。退出与进入适当重叠，不显示空白帧。
- 退出节点过渡完毕后再移出交互树；快速连续输入、中断和错误路径都要清理临时节点。保持焦点与必要的滚动状态。
- 复杂列表可用 FLIP：读取旧矩形 → 提交 DOM → 读取新矩形 → transform 过渡；布局读写分批，滚动和筛选时不逐帧重复测量。
- 不适合动画的源码编辑、摄影校色、长数据表可以直接局部替换，只保留短反馈。

## 控件与图表

- 分段底板按真实 offset/尺寸移动；字体加载、容器滚动、窗口和标签变化后重新测量。
- 滑块、拖拽与裁切手柄即时反馈；显示值与实际业务值一致，动画插值值不能冒充存储结果。
- 图表优先复用 SVG/Canvas 容器及数据节点，对路径与数值插值。不能插值时短交叉淡化，不先清空再重建空白框。
- 状态岛容器与内部内容分层；展开期间标题与关闭入口可见，反向操作从当前呈现状态到新终态。
- 选中、加载、成功、错误有各自语义状态，不只依赖发光或动画表达结果。

## 生命周期与性能

- 每组交互保留一条有效时间线；新输入取消旧动画并清理临时样式。业务数据和提交后的 DOM 是最终状态来源。
- 指针事件合并到单次待执行 rAF；动画结束释放不需要的 will-change、timer 和 observer。
- 优先 transform、opacity 和局部 CSS 变量；避免持续动画大面积 backdrop-filter、box-shadow、filter 或布局属性。
- 隐藏页面、离屏面板或不活动窗口暂停非必要循环；恢复时不补播历史帧。
- 系统或手动减少动效时取消空间运动及自动轮播并直接呈现终态；重新允许动效时不重播旧动画。
- 低性能模式保留相同业务内容、操作结果和可读性；关闭高成本模糊、粒子、倾斜和环境循环，必要时改用实色。

## 验收场景

| 操作 | 预期 |
|---|---|
| 1 秒内连续切换 5 次页面/Tab | 最终页面正确，无空白帧、残留节点或焦点丢失 |
| 面板展开到一半立即关闭，再打开 | 高度、透明度、焦点和可点击区域正确 |
| 连续切换图库筛选 | 列表、计数与选中底板一致，不反复重播全页入场 |
| 图表切换 7/30/90 天 | 图表与数值同步，不经历空数据占位 |
| 运行中切入减少动效 | 立即显示可操作的终态 |
| 页面隐藏后恢复 | 装饰不补播，业务状态不回退 |
| 390px 触屏、桌面鼠标、键盘 | 核心操作可完成，不依赖悬停 |
| 快速调整滑块并释放 | 拖动值与应用值一致，不被回弹覆盖 |

真实浏览器验收记录设备、刷新率、视口、DPR、主题、步骤、帧间隔与明显掉帧；按实际刷新周期评估（60Hz 约 16.7ms，120Hz 约 8.3ms），不向全部硬件承诺固定帧率。没有录屏或性能数据时标“未验证”。
